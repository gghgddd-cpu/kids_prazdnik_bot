# Детские видеопоздравления — Telegram-бот + ProxyAPI

Тестовый MVP для Windows. Бот предлагает два режима:

1. **Говорящий персонаж** — отправляет промпт в `heygen/heygen-video-1`. Это экспериментальный режим: модель может не произнести фразу дословно или не идеально синхронизировать губы. Проверяем первым тестом.
2. **Мультфильм с озвучкой** — генерирует мультяшный видеоряд через `x-ai/grok-imagine-video-1.5-lite`, создаёт отдельную русскую озвучку через TTS, добавляет имя на экран и собирает MP4 через FFmpeg.

## Что понадобится

- Python 3.11 или 3.12.
- Telegram-токен от `@BotFather`.
- API-ключ и положительный баланс ProxyAPI.
- FFmpeg для склейки видео и озвучки. Установить через `winget install Gyan.FFmpeg`, затем закрыть и заново открыть PowerShell. Проверь командой `ffmpeg -version`.

## Установка в Windows

1. Распакуй архив в отдельную папку, например `C:\kids-video-bot`.
2. Открой PowerShell в этой папке.
3. Выполни команды:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

4. В `.env` заполни `TELEGRAM_BOT_TOKEN` и `PROXYAPI_API_KEY`. Не присылай ключи в переписку.
5. Запусти:

```powershell
python bot.py
```

6. Найди своего бота в Telegram, отправь `/start` и пройди шаги.

## Первое тестирование и расходы

- Сначала сделай по одному короткому тесту каждого режима и проверь фактическую стоимость в кабинете ProxyAPI.
- Цена зависит от модели, длительности и разрешения. Генерация видео платная.
- Если модель не принимает `duration`, `aspect_ratio`, `generate_audio` или `resolution`, ProxyAPI вернёт ошибку. Скопируй только текст ошибки (без ключа), чтобы скорректировать параметры.
- Для экономии начни с `VIDEO_RESOLUTION=480p` и `VIDEO_DURATION_SECONDS=10`.
- Режим «говорящий персонаж» использует обычную генерацию видео с промптом. Не гарантируется, что модель воспроизведёт текст идеально. Если это не сработает, потребуется отдельный специализированный lip-sync/avatar API.

## Команды

- `/start` — создать поздравление.
- `/myid` — показать свой числовой Telegram ID для настройки администратора.
- `/admin` — открыть админ-панель (только для `ADMIN_IDS`).
- `/cancel` — сбросить текущий шаг.

## Приватность

Ключи хранятся локально в `.env`, который исключён из Git. Не сохраняйте и не публикуйте API-ключи. Для коммерческого запуска нужно добавить лимиты на заказы, очередь генераций и правила обработки детских данных.


### Исправление ошибки `HTTP 400: Unsupported video option`

В обновлённом `bot.py` добавлен автоматический повтор запроса с более простыми параметрами: сначала исключаются необязательные `aspect_ratio` и `generate_audio`, затем при необходимости `duration` и `resolution`.


### Исправление отправки готового видео в Telegram

Для aiogram 3 локальный видеофайл передаётся как `FSInputFile(path)`, а не как открытый файловый объект. В этой версии исправлена отправка MP4 в Telegram.


## Версия 3: один режим и выбор персонажа

- Оставлен один сценарий: говорящий персонаж.
- Добавлены 10 персонажей в меню.
- Убрана плашка с именем на самом видео; имя звучит в поздравлении и остаётся в подписи Telegram.
- Готовый ролик центрируется и обрезается под вертикальный 9:16 вместо чёрных полос. Это может обрезать края исходного горизонтального кадра; промпт просит держать лицо в центре.
- Во время генерации сообщение обновляется по этапам.

Обновление: остановить бота, заменить `bot.py`, оставить существующий `.env` без изменений и запустить снова. Требуется FFmpeg в PATH.


## Версия 4: горизонтальный формат и фон по поводу

- Готовый файл больше не обрезается в 9:16. Он приводится к горизонтальному 16:9 с разрешением 1280×720, без растягивания изображения.
- В промпт добавлена явная композиция landscape 16:9.
- Добавлены описания фона под каждый повод: день рождения — шарики и конфетти; Новый год — ёлки, гирлянды и снег; достижение — звёзды и праздничные эффекты; поддержка — мягкая волшебная атмосфера.
- Обнови только `bot.py`, `.env` оставь без изменений.

Примечание: генеративная модель не всегда точно выполняет промпт; если исходный клип сама модель выдаёт с неудачным фоном или портретным кадром, это всё ещё зависит от возможностей модели.


## Режим «Своё поздравление»

При запуске пользователь выбирает готовый шаблон или собственное поздравление. Во втором режиме он вводит имя ребёнка, описывает повод (до 120 символов), персонажа (до 100 символов) и полностью свой текст (до 500 символов). Этот текст отправляется модели как точная реплика персонажа; фактическое произношение и соблюдение текста зависят от возможностей видеомодели.


## Версия 6: пользователи, администратор и заглушка оплаты

### Подготовка `.env`

Добавь/измени параметры в существующем `.env` (не перезаписывай ключи):

```dotenv
ADMIN_IDS=123456789
VIDEO_PRICE_RUB=149
DEMO_GENERATION_ENABLED=true
MAINTENANCE_MODE=false
BOT_DB_PATH=kids_video_bot.sqlite3
```

Укажи свой числовой Telegram ID в `ADMIN_IDS` (не username). Можно указать несколько ID через запятую. Если не знаешь ID, запусти бота и отправь `/myid` — бот покажет твой числовой Telegram ID.

### Для пользователей

После настройки поздравления пользователь получает карточку заказа с ценой и кнопками «Оплата — скоро», «Тестовая генерация» (если включена) и «Отменить заказ». Реального списания денег пока нет. Тестовая генерация по умолчанию включена для продолжения разработки; её можно выключить из админки.

### Для администратора

Команда `/admin` доступна только ID из `ADMIN_IDS`. Панель позволяет посмотреть статистику, список пользователей, последние заказы, включать/выключать бесплатную тестовую генерацию, включать/выключать техническое обслуживание и делать текстовую рассылку.

Данные хранятся в SQLite-файле `kids_video_bot.sqlite3` рядом с ботом. Сделай резервную копию этого файла перед переносом/обновлением. Цена — только отображаемая заглушка, оплаты и статуса `paid` автоматически пока нет. Рассылку используй только для сообщений пользователям, которые сами запускали бота; Telegram не позволяет написать пользователю, который не открыл чат с ботом.
